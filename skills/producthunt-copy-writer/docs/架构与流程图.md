# PH 文案撰写 · 架构与流程图

## 本技能的四层结构

```mermaid
flowchart TB
  U["使用层：发布日冲刺指挥官 的使用者"]
  T["触发层：PH 文案撰写"]
  X["执行层：5 个步骤"]
  O["产出层：PH 文案包"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 即将上线新产品/大版本的全体独立开发者与出海小团队；员工定位：把"一次性高压发布"变成清单化流程的发布周总指挥 |
| 触发层 | 关键词 / 显式点名「PH 文案撰写」；触发方式：用户提出需求 |
| 执行层 | **接收输入**：确认拿到的是「产品说明」，先做完整性检查。 → **生成 tagline/首评/maker comment 全套 PH 文案**：按该定义执行，并把用到的输入项显式写进产出。 → **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。 → **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。 → **回指自检**：逐个数字回指输入来源，回指不上的删掉。 |
| 产出层 | PH 文案包 |
